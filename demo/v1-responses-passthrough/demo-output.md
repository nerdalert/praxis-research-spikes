Generated from a real test run on 2026-06-12. All output is verbatim.

**Environment:** codex-cli 0.139.0, no API keys, local mock backend only.

## Summary

This test proves Praxis can transparently proxy a real Codex CLI session
while rewriting the model name. Codex sent a request asking for
`codex-demo-client-name`. Praxis rewrote that to `llama-3.3-70b` before
forwarding to a mock backend. The mock returned a function call telling
Codex to create a file. Codex executed the command locally, sent the
result back through Praxis (model still rewritten), received a final
response, and exited cleanly. The proof file was created with the
expected content. No API key was needed — the entire loop ran against a
local mock. 14 structural verification checks passed.
